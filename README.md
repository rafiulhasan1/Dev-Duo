# 🚀 Dev Duo Portfolio

A modern and responsive portfolio website for two developers, built using React, Vite, Tailwind CSS, and Framer Motion.

## ✨ Features

- 👨‍💻 Two Developer Portfolio
- 🎨 Modern UI Design
- 📱 Fully Responsive
- ⚡ Fast Performance
- 🌙 Dark Theme
- 🎬 Smooth Animations
- 💼 Projects Showcase
- 🧠 Skills Section
- 📄 Experience & Education
- 📬 Contact Form
- 🔗 Social Media Links
- 👤 Dynamic Member Details Page
- 🚀 Built with Modern React

---

## 🛠️ Tech Stack

- React 19
- Vite
- Tailwind CSS 4
- React Router DOM
- Framer Motion
- React Icons
